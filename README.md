# 分数・小数ラボ（bunsu-lab）

分数・小数の たし算・ひき算・かけ算・わり算を、図で一歩ずつ体感できるWebアプリです。「おうちラボ」の1つ。

**公開ページ:** https://bunsu-lab.vercel.app/

## できること
- 分数の＋−：テープ図で「通分」を見る
- 分数の×：面積図で、分子どうし・分母どうしをかける理由を見る
- 分数の÷：同じ大きさに切りそろえて「いくつ分入るか」を数える
- 小数の＋−：100ますグリッドと、小数点をそろえた筆算
- 小数の×：0.1×0.1＝0.01 のますを数える
- 小数の÷：数直線でジャンプして「いくつ分」を数える

答えは最後の手順まで「？」で隠れます。数は ＋／− ボタンで変えられ、「おまかせ問題」でランダム出題もできます。

## 構成
`index.html` 1枚だけ（ビルドなし）。Vercelはそのまま静的配信。
